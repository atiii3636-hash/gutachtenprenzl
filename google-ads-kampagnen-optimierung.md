## TEIL C — Strukturelle Fixes (DER eigentliche Hebel gegen 80 % Streuanrufe)

Negatives behandeln Symptome. Diese drei Punkte behandeln die Ursache:

### C1 · Standort: „Anwesenheit oder Interesse" → „Anwesenheit" 🔴 SOFORT
- Einstellungen → Standorte → Standortoptionen → **„Anwesenheit: Personen an deinen Zielstandorten"** (NICHT „Anwesenheit oder Interesse").
- Eliminiert auf einen Schlag alle Anrufer, die nur *über* Berlin suchen oder gar nicht hier sind. Spart mehr als jede Stadt-Negativliste.

### C2 · Gebotsstrategie: weg von „Klicks maximieren" 🔴 GRÖSSTER HEBEL
„Klicks maximieren" kauft *billige* Klicks, nicht *qualifizierte Anrufer* → strukturell Streu.

**Pfad:**
1. **Jetzt:** Bei „Klicks maximieren" ein **max. CPC-Limit** setzen (sonst zieht es die billigsten = schlechtesten Klicks). Z. B. 1,50–2,50 € testen.
2. **Anruf-Conversion-Tracking einrichten** (Pflicht für echten Fortschritt):
   - Google Ads → Ziele → Conversions → **Anrufe über Anzeigen** (Anruferweiterung) + **Anrufe an Telefonnummer auf der Website**.
   - Optional Mindest-Anrufdauer (z. B. 60 Sek.) als Qualitätsfilter.
3. **Nach ~15–30 Conversions:** Umstellen auf **„Conversions maximieren"** (ggf. mit Ziel-CPA). Google optimiert dann auf Leute, die wirklich anrufen — nicht auf billige Klicks. Das ist die eigentliche Lösung deines 80-%-Problems.

### C3 · Search Terms Report = wöchentlich prüfen
Nach 7–14 Tagen: Keywords → Suchbegriffe → Filter „Klicks > 0, Conversions = 0" → irrelevante Begriffe direkt als **Exact-Negative** ergänzen. Echte Suchdaten schlagen jede vorab erstellte Liste.
