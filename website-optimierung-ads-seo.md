## 3. Google-Ads-Optimierung

### 3.1 Anzeigengruppen-Struktur (eng = hoher QS)
Eine Anzeigengruppe pro Cluster, je 1 Landingpage. **Niemals alles auf die Startseite.**

| Anzeigengruppe | Keywords (Phrase + Exact) | Final-URL |
|---|---|---|
| KFZ Gutachter Berlin | "kfz gutachter berlin", [kfz gutachter berlin] | `/kfz-gutachter-berlin` |
| KFZ Sachverständiger Berlin | "kfz sachverständiger berlin", [kfz sachverständiger berlin] | `/kfz-sachverstaendiger-berlin` |
| Unfallgutachten Berlin | "unfallgutachten berlin", [unfallgutachten berlin] | `/unfallgutachten-berlin` |
| Auffahrunfall / Heckschaden | "auffahrunfall gutachten", "heckschaden gutachten" | `/heckauffahrunfall-berlin` |
| Parkschaden | "parkschaden gutachten berlin" | `/parkschaden-gutachten-berlin` |
| Totalschaden | "totalschaden gutachten berlin" | `/totalschaden-gutachten-berlin` |
| (optional) Bezirk-Kampagne | "kfz gutachter pankow" etc. | jeweilige Bezirksseite |

### 3.2 Anzeigentexte (RSA) — pro Anzeigengruppe
- **Headline 1 = das Keyword** (angepinnt), z. B. „KFZ Gutachter Berlin".
- H2/H3: „Kostenlos bei Fremdverschulden", „Gutachten in 24h", „TÜV-zertifiziert · 5,0★", „Mobil — wir kommen zu Ihnen".
- **Anzeigenerweiterungen (Pflicht, heben CTR → QS):** Anruf-Erweiterung (deine Nummer), Sitelinks (Unfallgutachten / Parkschaden / Totalschaden / Über uns), Snippets („Leistungen: Unfallgutachten, Parkschaden, Totalschaden"), Zusatzinfos („0 € bei Fremdverschulden", „Antwort in 30 Min.").

### 3.3 Konto-Einstellungen (größter QS-/Streu-Hebel — aus `google-ads-kampagnen-optimierung.md`)
1. **Standort: „Anwesenheit"** (nicht „Anwesenheit oder Interesse").
2. **Anruf-Conversions** einrichten (Anrufe von Anzeigen + Website-Anrufe). Website-Tracking läuft schon im Code (tel/WhatsApp + Formular).
3. Nach ~15–30 Conversions: **„Conversions maximieren"** statt „Klicks maximieren".
4. **Suchbegriffe wöchentlich** → Negatives pflegen.

## 4. SEO-Optimierung (On-Page)

### 4.1 Sofort-Fixes (aus dem QS-Audit, doppelt SEO-wirksam)
- 🔴 **Dünne/doppelte Seiten:** `kfz-sachverstaendiger-berlin` hat keinen Fließtext; fast Duplikat von `kfz-gutachter-berlin`. → Jeder Seite **eigenen, keyword-spezifischen Fließtext (150–300 Wörter) + 3–4 FAQ** geben (Vorlage: `unfallgutachten-berlin`).
- **Bewertungszahl vereinheitlichen** (Hero „45+", Seiten „47", Bezirk „40" → überall gleich).
- **Galerie-Bilder via `next/image`** (2-MB-Rohbilder dürfen nicht ungerendert raus → Core Web Vitals).

### 4.2 Titles / Meta (Keyword vorne, lokal, ein Trigger)
Aktuelle Titles sind ok. Prüfen, dass **jeder Title einzigartig** ist und Keyword vorne steht. Muster: `KFZ Gutachter Berlin – Unfallgutachten 24h, kostenlos | Gutachten Prenzl`. Meta-Description: Keyword + „kostenlos bei Fremdverschulden" + Telefonnummer + 24h.

### 4.3 Interne Verlinkung (Topical Authority)
- **Service-Seiten** (`unfallgutachten`, `parkschaden`, `totalschaden`, `heckauffahrunfall`) **untereinander** verlinken (machen sie aktuell kaum).
- **Blog → Geld-Seiten:** aus „was tun nach unfall" auf `/unfallgutachten-berlin` linken; aus „parkschaden was tun" auf `/parkschaden-gutachten-berlin`.
- Bezirksseiten verlinken schon untereinander ✅ — zusätzlich von der Startseite auf die wichtigsten Bezirke (Prenzlauer Berg/Pankow/Mitte) linken.

### 4.4 Realistische SEO-Strategie (wegen harter Konkurrenz)
- **Kurzfristig (Monate):** Bezirks- + Schadenart-Seiten ranken — wenig Wettbewerb. Hier Content vertiefen.
- **Mittelfristig:** Blog ausbauen (2–4 Artikel oben aus E), Google Business Profile pflegen (Bewertungen, Fotos, Beiträge) → **Local Pack** ist für lokale Suchen oft wichtiger als organische Plätze.
- **Head-Terms** („kfz gutachter berlin"): über Ads + Local Pack abdecken; organisch Platz 1 ist Langstrecke.

### 4.5 Google Business Profile (für lokal entscheidend)
Steht außerhalb der Website, ist aber dein stärkster lokaler Hebel: vollständiges Profil, Kategorie „Kfz-Sachverständiger", regelmäßig Bewertungen, Fotos, Beiträge. Verlinkt schon via Schema/Place-ID ✅.
